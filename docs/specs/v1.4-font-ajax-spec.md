# v1.4 — GHOST_FONT & GHOST_AJAX Detectors

## Overview

Two new finding types for the Ghost Code scanner targeting performance-impacting orphaned code patterns left by uninstalled Shopify apps.

## GHOST_FONT (Severity: MEDIUM)

**Problem:** Apps load custom fonts via `@font-face` declarations or Google Fonts `<link>` tags. After uninstall, these cause 100-500ms of wasted download time plus CLS from font-display issues.

### Detection Rules

1. `@font-face` declarations in inline `<style>` blocks whose `font-family` name can be attributed to a known app (via `identifyAppFromCode()` on surrounding snippet context)
2. `<link>` tags loading from `fonts.googleapis.com` or other font service URLs that can be attributed to a known app via surrounding code context

### False Positive Boundaries

- DO NOT flag `@font-face` for common theme fonts or standard Google Fonts used by theme — only flag when app-attributed
- Skip lines inside Liquid comment blocks
- Skip lines inside Liquid conditionals (LIQUID_CONDITIONAL_RE)
- Only flag if attribution to a known app succeeds

## GHOST_AJAX (Severity: HIGH)

**Problem:** App JavaScript makes `fetch()` / `XMLHttpRequest` calls to defunct app servers. Wasted network requests plus privacy concern (data still sent to third-party).

### Detection Rules

1. `fetch("https://...")` patterns in inline `<script>` blocks pointing to known app API domains
2. `new XMLHttpRequest()` followed by `.open("...", "https://...")` patterns pointing to known app domains
3. jQuery AJAX patterns: `$.ajax({url: "..."})`, `$.get("...")`, `$.post("...")` pointing to known app domains
4. URL strings assigned to variables or passed to functions that resolve to known app CDN domains

### False Positive Boundaries

- DO NOT flag fetch/XHR to Shopify-owned domains (cdn.shopify.com, etc.)
- Skip lines inside Liquid comment blocks
- Skip lines inside Liquid conditionals
- Only flag if the target URL can be attributed to a known app

## Implementation

Both detectors follow the GHOST_PRECONNECT pattern:

- Module-scope regex with /g flag, lastIndex reset before each use
- `insideComment` tracking for Liquid comment blocks
- `LIQUID_CONDITIONAL_RE` skip
- `buildSnippet()` for code context
- `classifySeverity()` for severity
- `identifyAppFromUrl()` + `identifyAppFromCode()` for attribution
- Only flag when app-attributed (no unknown domain flagging)

## Prisma Changes

Add `GHOST_FONT` and `GHOST_AJAX` to the `FindingType` enum.

## Severity Defaults

- `GHOST_FONT`: MEDIUM
- `GHOST_AJAX`: HIGH
